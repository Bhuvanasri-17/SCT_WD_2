# Stopwatch Web Application

## 📌 Project Overview
The Stopwatch Web Application is an interactive and user-friendly web project developed using HTML, CSS, and JavaScript. This application allows users to accurately measure and record time intervals with functionalities like start, pause, reset, and lap time tracking.

This project was created as part of the SkillCraft Technology Web Development Internship.

## 🚀 Features
- ▶️ Start Stopwatch
- ⏸️ Pause Stopwatch
- 🔄 Reset Stopwatch
- 📝 Lap Time Tracking
- 📱 Responsive User Interface
- ⏱️ Accurate Time Measurement

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
